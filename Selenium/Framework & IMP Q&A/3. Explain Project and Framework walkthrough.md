###3. Explain Project\Framework walkthrough

- ***Framework type***: Hybrid Framework (Data-Driven), Page Object Model (POM) design pattern with Cucumber BDD and TestNG.
- **Tools used**: Selenium WebDriver, Java, TestNG, Maven, Extent Reports, Jenkins, Git, Log4j and RestAssured for API automation. 
- **Folder structure**: 
  - `src/main/java` → Page classes, Utility classes, Base class
  - `src/test/java` → Test classes
  - `src/test/resources` → testng.xml, config/properties files, test data (Excel/JSON)
  
- **Flow Framework structure **: 
  - `BaseClass` handles driver initialization/teardown (setup & teardown using `@BeforeSuite`/`@AfterSuite` or `@BeforeMethod`/`@AfterMethod`).
  - `PageObjects` contain locators + methods (POM design pattern, often with `PageFactory`).
  - `TestNG` classes call page methods and add assertions.
  - Data is externalized via Excel/JSON/properties files (Data-Driven Testing with `@DataProvider`).
  - Reports generated via Extent Reports; logs via Log4j.
  - Integrated with Jenkins for CI/CD — triggered on code commit or scheduled runs.
  - Failures captured via screenshots attached to reports.

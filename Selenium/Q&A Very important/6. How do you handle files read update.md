## 6. How do you handle files (read/update a file)

**Reading a text file:**
```java
BufferedReader reader = new BufferedReader(new FileReader("data.txt"));
String line;
while ((line = reader.readLine()) != null) {
    System.out.println(line);
}
reader.close();
```

**Writing/updating a text file:**
```java
FileWriter writer = new FileWriter("data.txt", true); // true = append mode
writer.write("New line of data\n");
writer.close();
```

**Reading Excel (Apache POI)** — common in data-driven frameworks:
```java
FileInputStream fis = new FileInputStream("TestData.xlsx");
Workbook workbook = new XSSFWorkbook(fis);
Sheet sheet = workbook.getSheetAt(0);
Row row = sheet.getRow(1);
String value = row.getCell(0).getStringCellValue();
workbook.close();
```

**Reading Properties file (for config):**
```java
Properties prop = new Properties();
FileInputStream fis = new FileInputStream("config.properties");
prop.load(fis);
String url = prop.getProperty("baseURL");
```

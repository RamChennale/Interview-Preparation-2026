## 11. Framework related questions (general prep points)

Be ready to explain:
- **Why POM (Page Object Model)?** — separates test logic from UI locators, improves maintainability (one place to update locators if UI changes), 
										improves reusability.

- **POM vs Page Factory** — Page Factory uses `@FindBy` annotations and `PageFactory.initElements()` for lazy initialization of elements.

- **Data-Driven Framework** — test logic separated from test data (Excel/JSON/DB), same script runs with multiple data sets via `@DataProvider`.

- **Hybrid Framework** — combination of POM + Data-Driven + Keyword-Driven.

- **BDD Framework (Cucumber)** — Feature files (Gherkin: Given/When/Then) mapped to step definitions in Java.

- **CI/CD integration** — Jenkins pipeline triggers Maven `test` goal, generates reports, sends notifications.

- **Reporting** — Extent Reports, with pass/fail/screenshot attached.

- **Version control** — Git branching strategy (feature branch → PR → merge to main/develop).

## 4. Explain OOPs (and how you use it in your project)

The 4 pillars of OOPs:

1. Inheritance
2. Eencapsulation
3. Polymorphism
4. Abstraction

**Example answer:** "In my framework, 
					
					I use ***inheritance*** where all page classes extend a common BasePage class initialization/teardown 
					(setup & teardown using `@BeforeSuite`/`@AfterSuite` or `@BeforeMethod`/`@AfterMethod`) and 
					also that BasePage has reusable methods like `click()`,	`waitForVisibility()`. 
					
					I use ***encapsulation *** 
					Wrapping data (fields) and methods together, using private fields with getters/setters | 
					WebElements declared `private`, accessed only via methods in Page classes out*** Modele/POJO classes *** and 
					By keeping WebElements private and exposing only action methods. 
					
					***Polymorphism *** is used through method overloading for utility functions like 
					`waitForElement(WebElement e)` & 
					`waitUntilVisible(WebElement e)` & 
					`waitUntilClickable(WebElement element)`;and 
					***abstraction*** 
					Hiding implementation details, exposing only functionality
					and is achieved since WebDriver itself is an interface — I don't need to know how `driver.click()` works internally, 
					just call it."
